# Invitación de XV años — Emily Nicole

## Publicar en GitHub Pages

1. En GitHub, abre el repositorio donde quieres publicar la invitación.
2. Selecciona **Add file → Upload files**.
3. Sube `index.html` desde esta carpeta (debe quedar en la raíz del repositorio, no dentro de otra carpeta).
4. Pulsa **Commit changes**.
5. Ve a **Settings → Pages** y en **Build and deployment** selecciona `Deploy from a branch`, rama `main` (o la rama principal del repositorio) y carpeta `/ (root)`. Guarda.
6. Espera unos minutos y abre la URL de GitHub Pages.

## Personalizar el enlace de Canva

En `index.html`, busca `PEGA_AQUI_TU_URL_DE_CANVA` y reemplázalo por el enlace público de tu invitación o video de Canva, conservando las comillas. Guarda y vuelve a subir el archivo.

## Detalles
- El fondo floral está integrado en el HTML.
- Las fuentes externas requieren conexión a internet.
- El enlace de Google Maps y el botón de WhatsApp están incluidos.
- Algunos navegadores no permiten reproducir audio automáticamente sin interacción.
